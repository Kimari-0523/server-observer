# AI 接入与客户端确认（接口 2.2）

本教程同时适用于自建服务器版与纯 Cloudflare 版。平台域名用你自己部署的最终 HTTPS 地址，`https://monitor.example.com` 只是示例。无需给 AI SSH 私钥、维护密码或模型 API Key。

## 人员配置步骤

1. 使用账号密码、飞书或 OIDC 登录平台，按管理员配置选择。
2. 输入维护密码，进入 **AI操作接口**，填写明确名称，例如“办公电脑 / 运维助手”，创建长期授权。创建人来自已登录身份，自动记录姓名与时间。
3. 下载仓库的整个 [ai-client 文件夹](../ai-client/README.md)，交给 AI 读取 README。该文件夹只有说明和 4 个脚本，没有密钥和旧包。
4. 让 AI 检查 Python 3.10+，复制脚本到固定目录，启动本机授权窗口。Windows 启动器需要 `-PythonExecutable <实际路径> -PlatformUrl <你的HTTPS地址>`；人员粘贴令牌并保存，不发到聊天。非 Windows 在人员自己的终端隐藏输入。
5. 让 AI 按工具能力注册 MCP、CLI 或可信 HTTP 适配器，重载后读取服务器列表、状态和历史。只保存配置不算接通。

令牌手动撤销前有效，关闭网页、退出维护或重启平台不会失效；自动包含以后新增的服务器。停止某客户端时，在网页撤销对应名称，而不是只关闭窗口。旧版临时令牌不自动迁移，请重新创建具名长期授权。

## 不同工具怎样接入

| 能力 | 接入 | 确认 |
| --- | --- | --- |
| Codex、Antigravity、DeepSeek Harness 等提供本地 MCP | Python 进程 + `monitorctl.py mcp` | Windows 默认本机问题窗口；其他系统按实际 MCP form 能力 |
| 已验证支持 MCP 原生表单 | 参数改为 `monitorctl.py --confirmation native mcp` | 工具原生问题表单 |
| 只支持本地命令 | `monitorctl.py execute` | Windows 本机窗口或人员可操作的终端 |
| 支持 HTTP/OpenAPI 或自定义插件 | [OpenAPI](../web/ai-api.json) + 可信后台适配器 | 适配器自身向人员提问 |
| 仅有聊天、没有交互或工具 | 先配置适配器 | 保留待确认，不自动执行 |

是否兼容取决于具体版本实际能力，不按品牌假定。HTTP 地址不能填成 MCP URL。详细命令、六个工具名和 HTTP 确认协议见 [AI 配置说明](../ai-client/README.md)。

## 日常使用

查看状态无需执行 Shell。AI 可以读取 CPU、内存、多磁盘、服务、Docker 和最多 365 天历史，需说明 `last_seen` / `metrics_stale`，不能把缓存当作实时结果。

执行前，工具展示目标、IP 和完整 Bash / PowerShell 命令，再询问本次是否执行。平台不增加命令关键词拒绝策略；明确同意才执行，明确选择不执行时停止。工具自身安全政策仍有效，平台不负责关闭第三方的限制。

关闭、稍后、超时、无交互能力或协议错误保留 `pending` 并显示原因，不能写成人员拒绝，也不能自动同意。需要继续时复用同一 `request_id` 与原始内容重新询问。执行结果未知先查询原任务，不能换编号盲目重复执行。

服务端持久保留授权、命令和 AI 审计，不按 30 天自动清理；应将存储增长纳入备份与容量预算，尤其是 Cloudflare 免费额度。审计区分登录创建人和 `client_reported`：服务器信任持有令牌的可信适配器，无法独立证明第三方实际点击人，不能把确认接口暴露成模型自批工具。

## 验收与排错

- 先读取列表、详情和历史；然后由人员核对并确认一次测试主机的 `hostname`。查询实际退出码和结果，并在网页查看审计。
- 确认窗口启动失败：检查本机脚本、用户桌面会话和 PowerShell，不能通过自动批准绕过。
- 原生表单自动 decline：检查客户端实际策略；Windows 可使用默认本机问题窗口。没有明确人员答复仍待确认。
- 401 表示令牌无效或已撤销；通过本机窗口重新填写，不发送令牌到聊天。403/1010 还需检查边缘规则，连接器已提供明确 User-Agent。
- 更新脚本后重载 MCP 或新建会话；旧进程不会自动加载新源码。不要修改全局审批设置，不强制结束用户其他会话。

本地模拟、接口测试和特定客户端实测是不同的验收范围；本仓库不声明已逐品牌、逐版本实机测试。
